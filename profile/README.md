# hop-top

Custom URI schemes and surfaces for everyday work — `task://`, `hop://`,
`note://`, and more.

- **Spec**: <https://hop.top>
- **Polyglot SDKs**: [poly-uri](https://github.com/hop-top/poly-uri) (Go, TS, Python, Rust, PHP)
- **Read-only mirrors**: [uri](https://github.com/hop-top/uri) · [uri-ts](https://github.com/hop-top/uri-ts) · [uri-py](https://github.com/hop-top/uri-py) · [uri-rs](https://github.com/hop-top/uri-rs) · [uri-php](https://github.com/hop-top/uri-php)
